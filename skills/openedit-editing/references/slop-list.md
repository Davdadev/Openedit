# The slop list: what makes an edit look machine-made

Run through this before every final render. Each item is a common failure of automated edits.
If the user explicitly asks for a style on this list (for example meme edits), do it well, but
do not add it on your own.

| Slop | Why it hurts | Do instead |
|---|---|---|
| Zoom/punch-in on every sentence | Viewers feel pushed; emphasis stops meaning anything | <= 1 zoom per 15-20 s on long-form, each on a line that deserves it |
| Whoosh/swoosh on every cut | Announces the edit, fatigues fast | Silence on cuts; SFX only for a real on-screen event |
| Rainbow / karaoke word-highlight captions on long-form | Built for muted short-form scrolling, distracting at 10 min | `clean` or `minimal`; `bold-pop` only for shorts |
| Emoji in captions, or captions rewritten with hype words | Reads as a template; changes what the person said | Verbatim captions, lightly cleaned of fillers |
| Captions covering faces, hands or on-screen text | Hides the content | Check frames; move or shorten captions |
| Stock clip that only shares a keyword ("growth" -> plant sprouting) | Cliché; breaks trust | Literal footage of the actual thing, or no b-roll |
| Stock with different aspect, resolution, frame rate, grade or watermark | Looks pasted in | Match orientation, >= delivery resolution, similar light and colour |
| Generic "subscribe" / bell animation | Template signal | Only if the user asks, and once |
| Cuts so tight nobody breathes | Robotic delivery | 0.15-0.35 s air; longer after beats |
| Every pause the same length | Mechanical rhythm | Vary by meaning: short mid-thought, longer after points |
| Music wall-to-wall at constant level, too loud | Fights the voice | Duck ~20-24 dB under speech; let it breathe in gaps; sometimes no music |
| Meme SFX (vine boom, bruh, record scratch) | Cheapens serious content | Never, unless requested |
| Random glitch/shake/flash transitions | Distracting | Straight cuts; dissolves only for time passing |
| Lower thirds and callouts on everything | Clutter | Name once on first appearance; callouts for numbers that matter |
| AI-voice clichés in titles/graphics ("Unlock the secrets", "game-changer", "Let's dive in") | Instantly recognisable filler | Use the speaker's own words or plain labels |
| Upscaled/blurry or 720p stock in a 4K edit | Quality drop is visible | `minWidth` at least the delivery width |
| Ending on a fade to black in the middle of a sentence | Feels broken | End on a beat; music resolves |
| Over-saturated "pop" grade on every clip | Fake | Consistent, natural exposure and white balance |

## Self-check questions

1. Could I explain, out loud, why each zoom, SFX, b-roll and graphic is there?
2. Does the speaker still sound like themselves?
3. Would the user's audience notice the editing? (They should not, except where it helps.)
4. Did I look at frames of the final render, including under every caption?
